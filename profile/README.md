# PlaceAuth

**A common language for machines and places.**

PlaceAuth is an open interoperability project for autonomous systems operating in physical environments.

Its core protocol, the **Spatial Policy Protocol (SPP)**, enables physical environments to express operating requirements, autonomous systems to demonstrate conformance with those requirements, and both sides to establish evidence-backed operating profiles.
