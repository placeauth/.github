# PlaceAuth Press Kit

This kit is the current, self-contained asset package for PlaceAuth and PlaceAuth Foundation. It uses the approved layered spatial-plane emblem from `PressKit-Refresh`; it does not contain the earlier shield-and-pin mark.

## Primary mark

Use `source-svg/placeauth-horizontal-lowercase.svg` as the master logo in ordinary brand use. It is the canonical horizontal emblem-plus-`placeauth` lockup.

For dark fields, use `source-svg/placeauth-horizontal-lowercase-reverse.svg`. It has identical geometry and a paper-white wordmark and spatial planes.

## Package map

- `source-svg/` — canonical editable SVG masters and the comparison page.
- `png/horizontal/` — transparent, paper-field, and navy-field horizontal exports.
- `png/emblem/` — transparent emblem exports for compact uses.
- `png/stacked/` — centered stacked exports.
- `png/avatar/` — square profile-image treatments.
- `png/social-card/` — conservative social sharing cards.
- `quick-use/` — common website, email, GitHub, and social files.
- `preview/` — browser preview of the full lockup system.

## Naming

- Brand wordmark: `placeauth`
- Normal prose: `PlaceAuth`
- Organization: `PlaceAuth Foundation`
- Legal entity: `PlaceAuth Foundation, Inc.` — use only in legal text, not as a logo lockup.

## Digital minimums

Keep the horizontal lockup at 120 px wide or larger. Use the 600 px PNG for email signatures and the 1200 px PNG for websites that cannot serve SVG. Prefer SVG in modern web and print workflows.

See `GUIDELINES.md` for use rules and `preview/lockup-comparison.html` for a visual review.
