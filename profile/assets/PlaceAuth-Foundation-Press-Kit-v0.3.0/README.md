# PlaceAuth Foundation Press Kit

**Current public identity — refreshed September 25, 2026**

This is the approved public identity package for **PlaceAuth Foundation**. It matches the current PlaceAuth.org header: the deep-navy spatial emblem, the `PlaceAuth Foundation` wordmark, and the navy/cyan/sky visual system.

The previous rounded-P / amber-dot identity is not part of this package and should not be mixed with these assets.

## Approved forms

### Horizontal wordmark

The **PlaceAuth Foundation** wordmark and spatial emblem are the primary logo. Use the horizontal form wherever width allows.

### Foundation emblem

Use the hexagonal navy emblem with its location pin and contour lines for avatars, favicons, app icons, and narrow placements. It is the compact form of the same system, not a separate logo style.

### Background variants

- Use **navy transparent** on light fields.
- Use **paper transparent** on dark fields.
- Use the solid `on-paper` or `on-navy` exports where the platform needs a guaranteed background.
- The emblem’s navy badge, white pin, cyan contour, and sky contour are fixed parts of the mark.

## Clear space and minimum size

- Maintain clear space equal to at least one-quarter of the emblem’s height.
- Minimum horizontal-logo width: 160 px on screen.
- Minimum emblem size: 24 px on screen.
- At smaller sizes, use the emblem rather than compressing the full wordmark.

## Do not

- Do not use the earlier rounded `P` mark or amber dot with this Foundation system.
- Do not recolor, crop, rotate, outline, shadow, or add gradients to the emblem.
- Do not separate the pin from the contour lines or alter the hexagonal badge.
- Do not set the wordmark in a substitute typeface as a logo recreation; use the supplied assets.
- Do not attach a release number, tagline, or social icon to the logo artwork.

## Current release context

The public project release is **SPP v0.3.0 Experimental Preview**. The normative protocol specification remains **SPP 0.1**. Those facts may be used in adjacent editorial copy, but they are not part of the logo lockup.

## Package layout

- `quick-use/` — common files ready to publish.
- `png/horizontal/` — horizontal wordmark exports at web and social sizes.
- `png/emblem-transparent/` — transparent emblem exports.
- `png/avatar/` — square emblem exports on paper and navy fields.
- `png/social-card/` — 1200 × 630 share-card exports.
- `source-svg/` — scalable logo masters, including the exact current public emblem.
- `preview/` — visual reference sheet.
- `brand-tokens.css` and `brand-tokens.json` — palette values for implementation.
- `MANIFEST.sha256.txt` — checksums for every packaged file.
